# heyItsme

Hey, I’m **Muhammad Ahzan K N** — a Go backend developer based in Kochi, India. This is my personal portfolio: a place to introduce myself, share the backend systems and freelance work I’ve built, and make it easy to get in touch.

The portfolio puts my Go work first, including the UNICLUB Ecommerce REST API, StreamVideoGRPC, and UNICLUB Ecommerce Microservices. It also includes my frontend and freelance projects, such as Riayah Care. Some freelance work is private; I’m happy to share more about it on request.

## Take a look

The site includes selected projects, a short profile and work history, my technology toolkit, and contact links. The API explorer is a static documentation area for verified HTTP routes and gRPC methods. Those routes can be documented from the repositories; the APIs do not need to be deployed or live.

## Built with

- React and Vite
- JavaScript and CSS, with a responsive layout and dark/light themes
- Lucide icons
- Go, Gin, PostgreSQL, Redis, Docker, Kubernetes, AWS, and gRPC are among the technologies featured in my toolkit and projects

This is a static site and does not need a backend to run.

## Run locally

```bash
npm install
npm run dev
```

Open the local address printed by Vite. To create and preview a production build:

```bash
npm run build
npm run preview
```

## Personalize

- Replace `public/images/profile.jpg` to update my profile photo.
- Replace `public/images/riayah-care.png` to update the Riayah Care project preview.
- To add a project screenshot, place it in `public/images/` and set its `image` path in `src/main.jsx`.
- Update the email and LinkedIn links in `src/main.jsx` if they change.
- Add verified route documentation to `src/data/api-inventory.json` when the repository scan is ready.

The technology logos and web fonts are loaded from external CDNs, so they need an internet connection to appear.
